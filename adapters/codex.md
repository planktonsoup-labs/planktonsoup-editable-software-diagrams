# Codex Adapter

This repository provides reusable AI-agent guidance for generating and maintaining editable software diagrams.

Canonical documentation:

- SKILL.md (runtime behavior)
- AGENTS.md (maintainer governance)

Recommended workflow:

1. Read SKILL.md.
2. Select an example or template.
3. Generate editable source-based diagrams.
4. Preserve semantic structure and maintainability.

Preferred outputs:

- Mermaid
- draw.io XML
- source-controlled diagram assets

Avoid:

- raster-only outputs
- non-editable diagram formats
- excessive visual complexity
